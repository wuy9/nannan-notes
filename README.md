# 南南的沉淀库

个人沉淀库。单文件静态站点，一个 `index.html` 装下全部界面和逻辑，没有构建步骤、没有外部依赖。

- 站点：https://wuy9.github.io/nannan-notes/
- 数据仓库：https://github.com/wuy9/nannan-notes-data （私有，页面自动提交）

## 怎么用

打开站点就能写。「＋ 新增」记一条，标题、分组、正文、标签都有。正文选中文字后可以加粗、换颜色；每条能选一个卡片底色；标签可以单独配色（标签栏最右边的 ⚙）。

## 数据存在哪

两种模式，页脚左下角那个小圆点就是当前状态：

| 状态 | 含义 |
|---|---|
| 本地保存 | 只存在这台设备的浏览器（localStorage），换设备/清缓存会丢，靠「导出备份」保命 |
| 已存云端 · 22:30 | 每次保存都会提交到上面的私有数据仓库，换设备登录一下就能拿回来 |
| 正在保存… | 刚改完，正在写云端 |
| 保存失败 | 网络或令牌出问题，本地还有一份，恢复后自动重试 |

### 开启云端同步（一次性）

1. 打开 https://github.com/settings/tokens/new?scopes=repo&description=nannan-notes
   （可能要求输一次密码，这是 GitHub 的安全确认）
2. Expiration 建议选 **No expiration**，否则 30 天后同步会失效
3. 下面 `repo` 那一行已经勾好了，直接滚到底点 **Generate token**
4. 复制那串 `ghp_...`（只显示一次）
5. 回到站点，点页脚左下角「本地保存」→ 粘贴 → 「连接并同步」

令牌只存在你这台设备的浏览器里，不会进仓库、不会被其他访客看到。丢了或想作废，在同一页面撤销重发即可。

### 换设备 / 重装

新设备打开站点 → 点「本地保存」→ 粘同一个令牌 → 提示「云端已有 N 条」时选**确定**（用云端覆盖本地）。

## 开发备忘

- `index.html` 就是全部源码：CSS + 原生 JS，无框架。
- 调色板 8 色定义在 CSS 的 `[data-c="…"]`（浅色）和 `html[data-theme="dark"] [data-c="…"]`（深色）。
- 正文富文本保存的是 `data-c` 色号而不是 hex，所以深浅色切换时文字颜色会自动适配。
- 云端文件格式与「导出备份」一致：`{ v, updatedAt, tagColors, entries }`。
- 老版本数据（纯文本条目）首次加载会自动迁移成富文本，靠 `rich` 标记判断。
